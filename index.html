How to use — Step by step
Step 1 — Power on ESP32
Plug the ESP32 into a USB power source or laptop.
Step 2 — Connect
On laptop (USB cable): Click USB Cable → select AS7341_Sensor → Connect.
On Android (Bluetooth): Pair with AS7341_Sensor in phone settings first, then click Bluetooth here.
Step 3 — Set AUTO-STOP timer
Pick a duration from the AUTO-STOP dropdown (default 300 s). Select Manual only to stop yourself. The countdown shows in the timer box during measurement.
Step 4 — Measure your blank/reference first
Load the blank (e.g. DI water / DI+UHP) and click ▶ START, let it run, then ■ STOP. Keep gain, ATIME/ASTEP and the optical setup identical to what you'll use for the sample — the correction is only valid if these match. Then click 📍 Set Current Data as Reference in the sidebar — this averages the blank run into a baseline I₀ per channel.
Step 5 — Measure the sample
Click ▶ START again — this clears the old data and streams the sample. Once a reference is set, every reading is automatically converted to Transmittance (%T) and Absorbance (A) relative to I₀ — view these live on the Corrected tab. You can switch tabs or apps while it runs; collection continues in the background.
Step 6 — Save
After stopping, the save dialog appears automatically. Enter a name and click Save to Sheets — raw counts, the p1–p10 ratios, and (if a reference is set) Abs_/Trans_ columns for every channel plus the reference Clear value used, are all written.
Starting a new measurement always clears the previous data automatically — the stored reference is not affected, so it carries over into the next sample run until you clear it.
Browser: Google Chrome only. Not Firefox / Safari / Edge.
